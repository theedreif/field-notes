# Evaluation and Transfer

Evaluation should connect the learning journey to observable field behavior.

## Evidence chain

**FORMATIVE → PERFORMANCE → TRANSFER → OPERATIONAL EVIDENCE**

### Formative
Can the learner recognize and practice the component skill with guidance?

### Performance
Can the learner perform the integrated task under defined conditions and standards?

### Transfer
Does the behavior occur in the actual work environment without instructor prompting?

### Operational evidence
Do telemetry, records, observations, quality measures, incident data, or other appropriate sources show sustained capability?

## Level 3 behavior matrix

For each target behavior specify:
- objective;
- observable behavior;
- field evidence;
- standard/trigger;
- evidence source;
- observation period where relevant;
- response when performance misses.

Do not use learner satisfaction as evidence of Level 3 transfer.

## Diagnostic rule

When field performance misses, do not automatically retrain.

Diagnose whether the gap is:
- knowledge;
- skill;
- judgment;
- interface;
- workflow;
- workload;
- unclear authority;
- missing performance support;
- incentive;
- environment;
- system reliability;
- measurement.

Training solves only some performance problems.
