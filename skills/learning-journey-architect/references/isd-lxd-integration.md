# ISD + LXD Integration

## ISD question
**What must the learner perform, and how do we systematically map instruction to verified competence?**

ISD protects:
- task fidelity;
- objectives;
- conditions;
- standards;
- prerequisite structure;
- assessment alignment;
- safety/compliance requirements;
- performance evidence.

## LXD question
**Who is the learner, where is the friction, and what experience best develops and supports the required behavior?**

LXD examines:
- motivation;
- emotion;
- workflow;
- device/context;
- cognitive load;
- interface friction;
- accessibility;
- usability;
- scaffolding;
- journey continuity;
- transfer.

## Integration principle

Do not replace ISD with LXD.

Use:

**SYSTEMATIC RIGOR INSIDE HUMAN-CENTERED DELIVERY**

A polished experience that cannot verify capability is insufficient.

A technically aligned intervention that creates unnecessary cognitive and workflow friction is also insufficient.

## Journey-map fields

For each phase capture:
- target ISD objectives;
- learner mindset/emotion;
- cognitive load;
- touchpoint/media;
- LXD intervention;
- practice behavior;
- feedback;
- verification metric;
- transfer support.
