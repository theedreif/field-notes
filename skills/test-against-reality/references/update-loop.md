# Update Loop

## Evidence should change the system

Possible updates:
- revise a claim;
- narrow its scope;
- change a threshold;
- add a signal;
- clarify a limit;
- create a new scenario;
- alter a field tool;
- change an escalation trigger;
- add an evidence requirement;
- retire obsolete guidance;
- create a new hypothesis.

## Proportional updating

Match the size of the update to:
- evidence quality;
- relevance;
- repeatability;
- sample/context;
- consequences of being wrong;
- consistency with other evidence.

## Version discipline

Record:
- what changed;
- why;
- evidence;
- date/version;
- unresolved uncertainty;
- next test.

**TEST → LEARN → UPDATE → TEST AGAIN**
