# Field Test

A field test puts a claim, framework, tool, scenario, or assumption into contact with actual or representative operating conditions.

## Test design

Define:
- claim;
- context;
- actor;
- expected behavior;
- relevant conditions;
- limits;
- observable evidence;
- failure criteria;
- boundary conditions;
- update trigger.

## Useful questions

- What would we expect to observe if the claim is useful?
- What would count against it?
- Where should it stop applying?
- What alternative explanation could produce the same result?
- Is the test representative of the environment where the framework will be used?

A demonstration that cannot meaningfully challenge the claim is not a strong test.
